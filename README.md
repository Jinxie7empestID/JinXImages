## 🗂️ Directory Structure

The repository is organized into two main directories:

- `/sfw`: Contains Safe For Work (SFW) images.
- `/nsfw`: Contains Not Safe For Work (NSFW) images.

Within each directory, images are categorized into subfolders named after waifu or husbu characters in **PascalCase** format (e.g., `Sparkle`, `TomoAizawa`).

Each character folder must include a `credit.txt` file with the following details:

- Contributor's name
- Artist's name (if known)

Example `credit.txt`:
Contributor: JohnDoe Artist: JaneArtist

## 🤝 Contribution Guidelines

We welcome contributions to expand this collection. To add new images:

1. Fork the repository.
2. Place your images in the appropriate folder (`/sfw` or `/nsfw`).
3. Create or update the character folder in **PascalCase** and include a `credit.txt` file with your name and the artist's name (if known).
4. Submit a pull request with a detailed description of your additions.
