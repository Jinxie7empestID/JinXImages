## 📁 Directory Structure

The repository is divided into two primary categories:

- `/sfw/`: Safe for Work content, suitable for all audiences.
- `/nsfw/`: Not Safe for Work content, restricted to adults only.

Each directory contains subfolders named using **PascalCase** (e.g., `TomoAizawa`, `YorForger`, `KaguyaShinomiya`). These folders represent individual characters, whether waifus or husbus.

Each character folder **must include**:

- A `credit.txt` file with the format:

Contributor: YourNameHere Artist: OriginalArtistName (if known, else use "Unknown") Source: (Optional link to source like Pixiv, Danbooru, etc.)

This helps ensure proper attribution and traceability of image sources.

## 🤝 Contribution Guidelines

We welcome open-source collaboration. However, due to the nature of the content, contributors must follow these strict rules:

### 📌 Rules:

1. **No NSFW content involving minors**, even if it's fictional.
2. **Do not reupload or claim ownership of artworks** made by others unless:
   - You have the artist's permission.
   - The artwork is AI-generated and clearly marked as such.
3. **No AI-generated content** should falsely attribute to a real artist.
4. **Do not upload duplicates or low-resolution images.**

### 📤 How to Contribute:

1. **Fork** this repository.
2. Create or navigate to the appropriate `/sfw/CharacterName/` or `/nsfw/CharacterName/` folder.
3. Add your images and include a valid `credit.txt`.
4. Create a **clear and concise pull request** describing:
   - Character name
   - Source platform
   - Whether the art is AI-generated or hand-drawn
   - Any relevant tags

We will review your PR carefully to ensure compliance with community standards and artist respect.
